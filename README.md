# CodeSentry

CodeSentry is an advanced coding assessment platform with real-time monitoring and multi-language support. It includes AI-powered proctoring features like face recognition, chat monitoring, and a full-fledged coding environment for multiple languages.

## 🏗️ Project Structure

```
CodeSentry/
├── frontend/           # React-based frontend
├── javabackend/        # Spring Boot backend for main logic
├── pythonbackend/      # Python Flask backend for AI features (Face recognition, etc.)
```

Deployed Project :- [Link](https://code-sentry.vercel.app/)

## 🚀 Features

1. ✅ Coding Assessment Taker
2. 👁️ Face Recognition
3. 👥 Multiple Face Detection
4. 💬 Chat & Copy-Paste Monitoring
5. 💻 In-Browser Coding Environment
6. 🌐 Multiple Language Support

---

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Java Backend**: Spring Boot
- **Python Backend**: Flask, MediaPipe
- **APIs**: REST APIs
- **Other Tools**: Docker (optional for containerization)

---

## ⚙️ How to Run the Project

### 1. Clone the Repository
```bash
git clone https://github.com/Yashgabani845/CodeSentry.git
cd CodeSentry
```

### 2. Run the Frontend
```bash
cd frontend
npm install
npm start
```

### 3. Run the Java Backend
```bash
cd ../javabackend
mvn spring-boot:run
```

### 4. Run the Python Backend
```bash
cd ../pythonbackend
pip install -r requirements.txt
python server.py
```

---

## 📌 Notes

- Make sure you have Java, Maven, Python, Node.js, and npm installed.
- For face recognition to work correctly, ensure webcam permissions are granted.
- You can use Docker for containerizing the services (optional).
